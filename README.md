### Laptop Regression
This folder holds a generalized linear regression model that focuses on price data for various Houses (obtained from Kaggle). The price is the dependent variable, and the independent variables incldue features such as the numbers of bedrooms and bathrooms in each house. The model is primarily designed for making predictions, and it involves preprocessing the data, performing the regression, and taking steps to make sure that the assumptions of generalized linear models are met.
